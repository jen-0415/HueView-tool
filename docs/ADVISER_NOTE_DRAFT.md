During the implementation of Phases 7.4 and 7.5 of the HueView pipeline, four discrepancies were identified between the manuscript and the code. Three required revisions to Chapter 3 or the appendices, while one was a bug in the existing code that was subsequently fixed.

First, the HSV skin filtering thresholds used in Phase 7.4 were not specified in the manuscript. The implementation utilized the widely-cited rule of Kolkur et al. (2017), with hue between 0° and 50°, saturation between 0.23 and 0.68, and an additional value floor of 0.15 to handle numerically unstable hue in near-black pixels. These thresholds have been added to Stage 3 of the manuscript, along with the corresponding citation.

Second, the six region setups evaluated in the study differed between the build plan and the manuscript. The code followed the manuscript's specification of the five individual regions plus the combined Full Face setup, as this aligns with the structure of the results tables and the statistical tests in Phase 12.

Third, the jawline coverage stated in Table 3 of the manuscript did not match the region actually extracted by the code. The implemented region, built as the convex hull of face-oval landmarks below the jaw cutoff, spanned nearly the full width of the face, while Table 3 described a narrower central band. The table has been updated to reflect the anatomically correct region produced by the landmarks.

Finally, a bug was discovered in the cheek region definitions in the existing Phase 7.3 code. The landmark index groups for the left and right cheeks incorrectly combined face-oval points from one side of the image with eye points from the opposite side, causing both cheek masks to cover most of the face and overlap each other. This would have affected the separate Left Cheek and Right Cheek results reported in Appendix 3. The derivation has been corrected to bound each cheek by the lower eyelid, nose wing, lip line, and an inset ring of mesh points, ensuring the regions are anatomically situated and non-overlapping. Phase 7.3's outputs will be regenerated using the corrected definitions before proceeding to Phase 8.

These refinements strengthen the alignment between the HueView methodology as described and as implemented, and the corrected cheek regions in particular improve the pipeline's anatomical validity and the independence of the regional CIELAB measurements.

The revised HSV thresholds, jawline coverage, and cheek region derivation have been documented in the manuscript and the code respectively, and the six-region setup discrepancy has been resolved in favor of the manuscript's specification. With these adjustments, the HueView pipeline is well-positioned to proceed to the feature extraction and classification stages.
